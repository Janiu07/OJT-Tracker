## Reporting a Vulnerability

If you find a security issue in this project, please report it privately by opening an issue, or contact the repository owner directly. Include steps to reproduce, affected versions, and any relevant logs.

Do NOT include secrets or sensitive data in public issues.

## Security Contact

Contact: project maintainer via GitHub issues or email listed in the maintainer profile.

## Supported Versions

This repository contains the current supported branch. If you are reporting on older branches, please indicate the branch or commit hash.

## Disclosure Policy

Please allow maintainers reasonable time to respond and a chance to resolve the issue before public disclosure.
